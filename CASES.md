# Кейсы: как добавлять и редактировать

Все кейсы лежат в одном файле — `data/cases.json`. Страница `cases.html` читает его при загрузке, никаких таблиц, скриптов и Actions.
Порядок карточек на сайте = порядок в файле. Фильтры по тегам собираются сами из тегов кейсов.

## Способ 1 — админка Pages CMS (удобно, с загрузкой картинок)

1. Открой https://app.pagescms.org и войди через GitHub.
2. Выбери репозиторий `SborNutra/gallery01` (при первом входе GitHub попросит дать Pages CMS доступ к репо).
3. Слева раздел **Cases** → кнопка добавления элемента → заполни поля, загрузи обложку → **Save**.
   Картинка сама сохранится в `assets/cases/`, изменения закоммитятся в `main`, через минуту GitHub Pages обновит сайт.
4. Элементы списка можно перетаскивать — так меняется порядок на странице.

Настройки админки — в файле `.pages.yml`.

## Способ 2 — руками через GitHub

1. Загрузи обложку в папку `assets/cases/` (Add file → Upload files).
2. Открой `data/cases.json` → карандаш → скопируй любой блок `{ ... }` и поправь значения. Между блоками должна стоять запятая.
3. Commit changes.

## Поля

| поле | что это |
|---|---|
| `title` | название кейса (обязательно) |
| `subtitle` | подпись под названием, например «Rebranding» |
| `year` | год |
| `cover` | обложка: `/assets/cases/имя.jpg` или полная ссылка. Можно видео `.mp4`/`.webm` |
| `tags` | список тегов: `["branding", "web"]` |
| `url` | куда ведёт клик (Behance, hsedesign и т.п.) |
| `featured` | `true` — карточка на всю ширину |
| `hidden` | `true` — кейс спрятан (черновик) |

Обложки лучше держать горизонтальными 4:3 (у большой карточки — 16:9), ширина ~1600–2000 px.
