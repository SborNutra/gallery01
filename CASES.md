# Кейсы: как добавлять и редактировать

Все кейсы лежат в одном файле, `data/cases.json`. Страница `cases.html` читает его при загрузке.
Порядок карточек на сайте совпадает с порядком в файле.

## Способ 1: админка Pages CMS (удобно, с загрузкой картинок)

1. Открой https://app.pagescms.org и войди через GitHub.
2. Выбери репозиторий `SborNutra/gallery01`.
3. Слева раздел **Cases** → добавь элемент, заполни поля, загрузи обложку и 2–4 кадра для ховера → **Save**.
4. Элементы списка можно перетаскивать, так меняется порядок карточек.

Картинки можно грузить любого размера. Через минуту после сохранения GitHub сам сожмёт их в WebP
(workflow **Optimize Media**), и сайт обновится.

## Способ 2: просто вставить ссылки

В `cover` и `gallery` можно вставлять прямые ссылки на картинки (Behance, hsedesign и т.п.).
Workflow сам их скачает, сожмёт, положит в `assets/cases/` и перепишет ссылки на локальные.
Сайт перестанет зависеть от чужих серверов.

Ссылку на картинку с Behance проще всего взять так: открыть картинку в кейсе → правый клик → «Копировать адрес изображения».

## Поля

| поле | что это |
|---|---|
| `title` | название кейса (обязательно) |
| `subtitle` | подпись под названием, например «Rebranding» |
| `year` | год |
| `cover` | обложка. Без обложки покажется заглушка с названием |
| `cover_video` | необязательно: тихий луп 5–10 с поверх обложки (webm и/или mp4), играет, когда карточка на экране |
| `film` | необязательно: полный ролик, под карточкой появляется кнопка «watch film» с плеером |
| `gallery` | 2–4 кадра, которые листаются при наведении (на телефоне листаются сами, когда карточка на экране) |
| `tags` | теги, показываются под карточкой |
| `url` | куда ведёт клик |
| `featured` | `true` — карточка на всю ширину. Если в ряду осталась одна карточка, она тоже растянется сама |
| `hidden` | `true` — кейс спрятан (черновик) |

## Shards (работы)

Работы лежат в `data/shards.json`, редактируются в той же админке, раздел **Shards (works)**.
Google-таблица больше не используется.

1. Pages CMS → **Shards (works)** → добавить элемент.
2. Загрузи файл (картинку или видео, попадёт в `assets/pics/`), поставь дату и теги → **Save**.

Остальное заполнится само: имя для ссылки (`index.html#имя`) берётся из имени файла,
размер — из имени вида `Name-1080x1920.jpg` или из самого файла. Workflow делает превью
для сетки, считает цвет для фильтра, обновляет RSS-ленту `feed.xml` и картинки для превью ссылок.

У каждой работы своя ссылка: открой работу и нажми «copy link».

## Видео

Видео не сжимаются автоматически, их лучше готовить заранее. Ориентиры:
луп обложки — 1280px, без звука, до 1 МБ; ролик — 1280px, 30 fps, до ~10 МБ.
Если положить и `.webm` (VP9), и `.mp4` (H.264), браузер сам выберет подходящий.
